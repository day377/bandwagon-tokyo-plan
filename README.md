## 线路与延迟：三网 CMI 直连的真实水平

回程主要走中国移动 CMI 直连，全国平均延迟 77.2ms，电信平均 75.7ms、移动 77.1ms、联通 89.7ms，这个成绩在同价位日本 VPS 里属于第一梯队。

先说一个多数宣传不会展开的细节：所谓“三网直连”，主要指的是回程。上线时的测评给出了完整路由——去程电信走 CN2、联通走 AS4837、移动走 AS9808，三条线路各走各的；回程以中国移动 CMI 为主，部分情况下可能绕行电信 163 网络。换句话说，移动用户的体验最接近宣传口径，电信和联通用户要看具体地区和时段。

上线时公开的全国测速数据如下：

| 线路 | 平均延迟 | 最快节点 |
| --- | --- | --- |
| 全国（276 个节点） | 77.2ms | 上海 32.4ms |
| 电信 | 75.7ms | 上海 36.4ms |
| 联通 | 89.7ms | 杭州 32.5ms |
| 移动 | 77.1ms | 金华 46.1ms |

分区域看，华东平均 70.0ms、华中 66.9ms，是表现最好的两个区域；华南平均 86.9ms、西北 91.4ms 相对慢一些。个别节点出现过 568.5ms 的极端值（河北石家庄电信），看延迟时以平均数为参考更有意义。

带宽方面，平峰时段用苏州电信 5G 宽带测得上传 2.2Gbps、下载 1.1Gbps。2.5Gbps 的标称带宽在晚高峰能剩下多少，因地区和时段而异，这一点任何日本 VPS 都一样。
